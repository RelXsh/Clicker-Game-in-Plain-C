# Clicker-Game-in-Plain-C
*This piece of software is the first game we've managed to get running using the Raylib game library with C.*

## Functionality
This game prototype is as bare bones as one could be. 
You can:
- Click a button to earn points
- Upgrade your button to earn more points per click
- Exit the game & have your data saved
- Open the game and have your saved data loaded (if it exists)

### Saving data!
The game saves are stored near the main.exe in a save.txt file. You can open it and change the values. 
First number depicts the current amount of points you have, while the second number depicts the points you get per button click.
